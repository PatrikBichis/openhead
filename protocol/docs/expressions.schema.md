# Expressions

**Title:** Expressions

|                           |             |
| ------------------------- | ----------- |
| **Type**                  | `object`    |
| **Required**              | No          |
| **Additional properties** | Not allowed |

**Description:** A theme's `expressions.json`: a face parameter preset per emotion. Only `neutral` is required; missing shared names fall back to it. Parameters a preset leaves out keep the theme's neutral value.

| Property                       | Pattern | Type   | Deprecated | Definition | Title/Description                            |
| ------------------------------ | ------- | ------ | ---------- | ---------- | -------------------------------------------- |
| + [expressions](#expressions ) | No      | object | No         | -          | -                                            |
