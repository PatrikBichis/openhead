Support

OpenHead Robot Face för iOS och iPadOS

Behöver du hjälp eller har du hittat ett fel? Skapa ett ärende på GitHub (gärna på engelska). Ta med appens version (Settings → About), din enhetsmodell och vad du provade. Med utvecklarläget påslaget visar openhead logs vad appen gjorde.

Kom igång

  1. Öppna appen med telefonen liggande. Ansiktet visas.
  2. Installera verktygen på en dator i samma wifi: uv add "openhead @ git+https://github.com/PatrikBichis/openhead@v0.4.0#subdirectory=python"
  3. Kör openhead discover för att hitta huvudet och sedan openhead pair --device <adress>. En sexsiffrig kod visas på skärmen i 60 sekunder; skriv in den när du blir tillfrågad.
  4. Prova openhead emotion happy eller openhead subtitle "Hej" --mouth.

README (på engelska) beskriver protokollet, Python-klienten, simulatorn och MCP-servern för AI-agenter.

Vanliga problem

Datorn hittar inte eller når inte huvudet

Båda måste vara i samma wifi-nätverk (gästnätverk hindrar ofta enheter från att se varandra). Se till att appen är öppen och ligger överst, och att "Lokalt nätverk" är tillåtet för OpenHead i iOS Inställningar → Integritet och säkerhet → Lokalt nätverk. Huvudets adress visas i appens inställningar.

Ingen parningskod visas

Koden visas när en oparad styrenhet ansluter, inte vid sökningen. Kör openhead pair --device <adress>; den ansluter först och frågar sedan efter koden. Efter fem felaktiga koder låses parningen i fem minuter.

Skärmdumpar eller loggar säger att utvecklarläge krävs

Håll fingret på ansiktet i 1,5 sekunder för att öppna inställningarna och slå på Dev mode. Slå av det igen när roboten används.

En video eller bild visas inte

Huvudet hämtar media själv, så adressen måste gå att nå från telefonen. Video ska vara H.264 MP4. openhead show fil.mp4 serverar en lokal fil från din dator automatiskt.

GPS eller barometern skickar inget

Strömmarna gps och env kommer i version 0.3. Första gången frågar iOS om plats och Rörelse & fitness; om du nekade, slå på dem i iOS Inställningar → OpenHead. Inomhus kan det dröja innan GPS får en position.

Appen slutar svara när skärmen låses

iOS pausar appar i bakgrunden. På en robot, använd Guidad åtkomst (Inställningar → Hjälpmedel → Guidad åtkomst) för att hålla OpenHead överst; appen håller själv skärmen vaken.

Hur tar jag bort en styrenhet?

Öppna inställningarna (håll fingret på ansiktet) och ta bort den under Paired clients. Den måste paras igen för att kunna ansluta.
