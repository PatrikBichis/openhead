Support

OpenHead Robot Face for iOS and iPadOS

Need help or found a bug? Open an issue on GitHub. Please include the app version (Settings → About), your device model and what you tried. With dev mode on, openhead logs shows what the app did.

Getting started

  1. Open the app with the phone in landscape. The face appears.
  2. On a computer on the same Wi-Fi, install the tools: uv add "openhead @ git+https://github.com/PatrikBichis/openhead@v0.4.0#subdirectory=python"
  3. Run openhead discover to find the head, then openhead pair --device <address>. A 6-digit code appears on the screen for 60 seconds; type it at the prompt.
  4. Try openhead emotion happy or openhead subtitle "Hello" --mouth.

The README covers the protocol, the Python client, the simulator and the MCP server for AI agents.

Common problems

The computer cannot find or reach the head

Both must be on the same Wi-Fi network (guest networks often block devices from seeing each other). Make sure the app is open and in the foreground, and that "Local Network" is allowed for OpenHead in iOS Settings → Privacy & Security → Local Network. The head's address is shown in the app's settings.

No pairing code appears

The code appears when an unpaired controller connects, not on discovery. Run openhead pair --device <address>; it connects first, then asks for the code. After five wrong codes pairing is locked for five minutes.

Screenshots or logs say dev mode is required

Long-press the face for 1.5 seconds to open settings and switch on Dev mode. Switch it off again when the robot is in use.

A video or image does not show

The head fetches media itself, so the address must be reachable from the phone. Video should be H.264 MP4. openhead show file.mp4 serves a local file from your computer automatically.

GPS or the barometer sends nothing

The gps and env streams arrive in version 0.3. The first time, iOS asks for Location and Motion & Fitness; if you declined, switch them on in iOS Settings → OpenHead. Indoors, GPS can take a while to get a fix.

The app stops responding when the screen locks

iOS pauses apps in the background. On a robot, use Guided Access (Settings → Accessibility → Guided Access) to keep OpenHead in front; the app keeps the screen awake by itself.

How do I remove a controller?

Open settings (long-press the face) and remove it under Paired clients. It must pair again to connect.
